File format

Only name and price are required for each item. Option groups need a name and choices.

{
  "sections": [
    {
      "name": "Biryani",
      "items": [
        {
          "id": "BIR-001",
          "name": "Chicken Biryani",
          "price": 15.99,
          "description": "Basmati rice layered with spiced chicken",
          "aliases": ["chicken biriyani"],
          "tags": ["spicy", "halal"],
          "available": true,
          "options": [
            { "name": "Spice level", "min": 1, "max": 1,
              "choices": [{ "name": "Mild" }, { "name": "Medium" }, { "name": "Hot" }] },
            { "name": "Add-ons", "min": 0, "max": 2,
              "choices": [{ "name": "Extra raita", "price": 1.50 },
                          { "name": "Boiled egg", "price": 2.00, "available": false }] }
          ]
        }
      ]
    }
  ]
}
idOptional. Your own code (POS number, SKU). Keeps an item matched even if you rename it.
priceIn dollars: 15.99 or "15.99".
aliasesOther names callers say. Helps the AI understand speech.
availableOptional, default true. Also works on a choice.
min / maxHow many choices the caller picks. min: 1 makes it required. Defaults: 0 and 1.
choice priceExtra charge for that choice. Default 0.
